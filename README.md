## 🚀 Projet phare — SuiviDiabète SN

> Plateforme numérique de suivi des patients diabétiques, développée dans le cadre de mon **mémoire de Master II en Génie Logiciel**, visant à améliorer le suivi médical et la communication entre patients et professionnels de santé.

**Points clés de l'architecture :**

- 🏗️ Architecture **microservices** (Java 21, Spring Boot 3.2, Spring Cloud)
- 🔐 Authentification et autorisation avec **Spring Security & JWT**
- 🌐 **API Gateway** via Spring Cloud Gateway
- 🔎 Découverte des services avec **Netflix Eureka**
- ⚡ Communication inter-services avec **OpenFeign**
- 📨 Messagerie asynchrone avec **RabbitMQ**
- 💬 Communication temps réel via **WebSocket / STOMP**
- 🗄️ Persistance des données avec **PostgreSQL**
- 📚 Documentation API avec **Swagger / OpenAPI**
- 🐳 Conteneurisation avec **Docker** et pipeline **CI/CD** (GitHub Actions)
- 🩺 Conformité avec les standards **HL7 / FHIR**

`Java` `Spring Boot` `Spring Cloud` `PostgreSQL` `RabbitMQ` `Docker` `React` `JWT` `Swagger`
