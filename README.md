## 🚀 Projet phare : SuiviDiabète SN

Plateforme de suivi santé pour le diabète, bâtie en architecture microservices (9 services indépendants) — mon projet de fin d'études.

- **Backend** : Spring Boot, Spring Cloud (Eureka, API Gateway, Config Server)
- **Frontend** : React
- **Données & messagerie** : PostgreSQL, RabbitMQ
- **Infra** : Docker / Docker Compose
- **Qualité** : approche Contract-First (OpenAPI/SwaggerHub), tests de contrat Pact, CI/CD
- **Sécurité** : authentification JWT, gestion des rôles

Fonctionnalités développées : suivi glycémique et historique médical, prise de rendez-vous avec notifications, tableaux de bord, authentification par rôles.

🔗 [Voir le projet](https://github.com/azizndoye68/suivi-diabete-sn)
