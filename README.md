## 🚀 Projet phare

### 🏥 Plateforme de suivi des patients diabétiques

> Projet de mémoire de Master II en Génie Logiciel visant à concevoir une plateforme numérique permettant d'améliorer le suivi des patients diabétiques et la communication entre patients et professionnels de santé.

**Architecture :**

* 🏗️ Architecture basée sur les **microservices**
* 🔐 Authentification et autorisation avec **Spring Security & JWT**
* 🌐 API Gateway avec **Spring Cloud Gateway**
* 🔎 Découverte des services avec **Netflix Eureka**
* ⚡ Communication inter-services avec **OpenFeign**
* 📨 Communication asynchrone avec **RabbitMQ**
* 💬 Communication temps réel avec **WebSocket / STOMP**
* 🗄️ Persistance avec **PostgreSQL**
* 📚 Documentation des API avec **Swagger / OpenAPI**
* 🐳 Conteneurisation avec **Docker**

**Technologies principales :**

`Java` `Spring Boot` `Spring Cloud` `PostgreSQL` `RabbitMQ` `Docker` `React` `JWT` `Swagger`
